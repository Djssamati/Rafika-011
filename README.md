# تعبئة سهلة – Kotlin  (v2.2)

## الجديد في v2.2
- **الشاشة الرئيسية بلا تمرير**: كل شيء يظهر في شاشة واحدة (توزيع بالنِّسَب حسب حجم الهاتف).
- **ملء الشاشة كاملة**: الخلفية تمتد تحت شريط الحالة وشريط التنقل.
- **الواجهة الافتراضية = الزجاجية** (مثل التصميم)، وأيقونات الهاتف والكاميرا والترس مرسومة بالكود بدل الإيموجي.
- الحالة (نتيجة القراءة) صارت سطراً صغيراً مع صورة مصغّرة داخل بطاقة التصوير.

## (v2.1)

طريقة البناء:
1. افتح مجلد المشروع في Android Studio (Koala أو أحدث) وانتظر Gradle Sync (يلزم إنترنت لمرة واحدة).
2. Build > Build APK(s)  أو  شغّله مباشرة على الهاتف.
(أو ارفع المشروع إلى GitHub: الملف `.github/workflows/main.yml` يبني APK تلقائياً دون الحاجة إلى `gradlew`، ويجده في قسم Artifacts بعد انتهاء البناء.)

## الجديد في v2.1
- **أيقونة التطبيق**: صورة السيدة (الإطار الذهبي) هي أيقونة التطبيق في سطح المكتب.
  الملفات: `res/mipmap-*/ic_launcher*.png` + `res/mipmap-anydpi-v26/` + `res/drawable-nodpi/ic_launcher_foreground.png`.
- **ثلاث واجهات** يختار بينها المستخدم من الإعدادات (تُحفظ في الهاتف):
  1. زخرفة مغربية (Zellige)  2. زجاجي (Glass)  3. الرمّان (Pomegranate)
  الكود: `Themes.kt` (الألوان والخلفيات) – لتعديل لون أو شكل افتح الدالة `themeOf(...)`.
- **لغتان**: العربية والفرنسية من الإعدادات. كل النصوص في `Strings.kt`.
  الفرنسية تقلب اتجاه الشاشة تلقائياً من اليمين لليسار إلى اليسار لليمين.
- شاشة إعدادات مستقلة (`SettingsScreen.kt`) فيها: اللغة، الواجهة، رقم الإرسال، الرمز الأخير.

## ملفات المشروع
- `MainActivity.kt` منطق التطبيق (الكاميرا، القراءة، الإرسال)
- `MainScreen.kt` الشاشة الرئيسية
- `SettingsScreen.kt` شاشة الإعدادات
- `Themes.kt` الواجهات الثلاث
- `Strings.kt` النصوص العربية/الفرنسية
- `CameraScreen.kt`, `Ocr.kt`, `RechargeParser.kt` كما كانت (الأرقام تُقبل فقط إذا كانت ١٤ رقماً بالضبط)
